# JingcaiDesk V2.2｜竞彩受注清单核对与赛前概率研究

## 升级要点

本版本把**竞彩受注清单**和**第三方足球赛程**分离，不会将 TheSportsDB/football-data.org 的普通赛事自动视为中国体彩可售比赛。

- **竞彩受注清单页**：必须具有竞彩编号、主客队、联赛、北京时间开赛时间；支持合法来源CSV导入或用户获授权的HTTPS JSON接口。
- **核对状态**：CSV和供应商数据默认标记待核对；用户可对照 https://www.sporttery.cn/ 手动核对记录。软件不能独立证明清单来自官方。
- **历史数据**：使用 football-data.org API Token 获取指定赛事历史比赛；只有**双方名称唯一匹配、开赛时间相差不超过4小时，且赛前两队各有至少5场已结束比赛**才可建模。球队中英文名称不同需要人工配置别名。
- **概率模型**：赛前进失球均值代理值与独立泊松模型；显示主胜/平/客胜、比分前5名和0到7+总进球概率。未使用真实xG、伤停信息、实时赔率，非收益保证。
- **每天11:00**：Windows计划任务可定时刷新。配置授权竞彩清单接口后优先同步它；未配置时仅刷新第三方足球赛程。电脑关机/断网不会自动成功。

## GitHub Windows EXE 云端构建

建议新建仓库或清理旧版源文件。若整个项目上传为**一个子文件夹**，请将 `.github/workflows/build-windows.yml` 放到**仓库根目录**，否则Actions不会识别。构建脚本会递归寻找唯一的 `app.py` 并自动进入其目录。

Actions → Build JingcaiDesk V2.2 Windows EXE → Run workflow → main。成功后在 Artifacts 下载 `JingcaiDesk-V2.2-Windows-EXE`。

## 可导入CSV格式

请看 `sample/竞彩受注清单_格式示例非真实.csv`。必需列：

```
jc_no,date,kickoff,league,home,away
周三001,2026-11-04,2026-11-04 20:00,演示联赛,示例主队A,示例客队B
```

**样例完全虚构，不是受注比赛！** 列 `date` 是竞彩日期，`kickoff` 是北京时间，可能跨到次日。CSV来源必须合法且应核对竞彩编号与比赛双方。

## 通过授权API自动同步竞彩受注清单

在软件“数据源设置”填写你合法获得的 `feed_url`（HTTPS）与 Token。软件接受 JSON 数组或对象 `{"fixtures":[...]}`，每条记录包含上面6项字段；不支持任意网站直接当作API。无授权官方接口的情况下，**无法保证真正每天自动下载中国体育彩票全部受注场次**。

JSON示例（虚构）：

```json
{"fixtures":[{"jc_no":"周三001","date":"2026-11-04","kickoff":"2026-11-04 20:00","league":"演示联赛","home":"示例主队A","away":"示例客队B"}]}
```

即使数据由你配置的供应商返回，也会标记“供应商来源·待官方核对”，不冒充官方认证。

## 历史建模

在“数据源设置”配置 football-data.org Token，并指定联赛代码（如PL、PD、BL1、SA）；按其授权范围使用。其公开文档：https://www.football-data.org/documentation/quickstart

英文名称和中文名称不同，需要在 `%APPDATA%\JingcaiDesk\team_aliases.csv` 创建文件，格式参考 `sample/team_aliases_示例.csv`，例如 `official,provider`。只有**主客队均可唯一对应并且时间吻合**才计算概率。

## 注意

- 本产品为独立第三方研究终端，和中国体育彩票没有隶属关系。
- 赛程、球队统计、赛事运营可能更改，必须核对日期、编号、停售与公告；**概率不等于中奖保证，也不能仅凭高概率判定值得投注**。
- 中国大陆体育彩票仅通过合法渠道销售；本软件不提供投注、支付或自动购彩。
- 18岁以下不应购彩；请理性参与。
- **已完成离线单元测试。Windows EXE和真实网络接口仍需在用户机器上验证。**
